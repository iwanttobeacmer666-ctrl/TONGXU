# 同序 tongxu · Windows 工作台

双击 `D:\MY_SHARE\group-assistant\bin\desktop\tongxu.exe` 启动。请保留同目录的 DLL、JSON 等运行文件，也不要把 EXE 单独移走。程序使用本机已有的 .NET 10 Windows Desktop 运行时，不需要安装前端依赖。

中文产品名为「同序」，其他界面语言使用 `tongxu`。桌面入口统一为 `tongxu.exe`。项目根目录、后端及现有配置／资料路径不改名。

程序、运行时任务栏和桌面快捷方式共用内嵌的正式图标：保留蓝绿发光圆角边框，边框外为透明背景。图标资源位于 `desktop\Assets`，Windows ICO 包含 16–256 像素的十种尺寸。

可运行项目根目录的 `Create-DesktopShortcut.ps1` 创建或更新当前用户的桌面快捷方式。名称按 Windows 显示语言决定：中文（含简体、繁体等）为「同序」，其他语言统一为「TONGXU」，与程序内选择的界面语言无关。系统显示语言改变后，重新运行此脚本会更新名称；不添加后台监视或登录任务。

快捷方式引用 `tongxu.exe` 内的图标，不依赖设计预览或临时图片；脚本只改名目标匹配的本应用快捷方式，同名快捷方式若指向其他程序则拒绝覆盖。其他安装位置可以用 `-ExecutablePath` 指定完整 EXE 路径。该脚本动态查找当前用户桌面，后续分发可复用，不写死当前电脑的用户名。

打开管理台只读取本地状态。点击“启动服务”并确认后，才会运行原有服务并连接企业微信；“专用 Codex 登录”也需要单独点击。服务运行时点击窗口关闭会隐藏到托盘；服务未运行时会彻底退出。启动检查或操作尚未确认时也会保留托盘入口。单击托盘图标或右键选择“打开主界面”可恢复窗口；选择“退出”会先通过现有流程停止全部群服务及其任务，确认服务离线、启动辅助进程结束后再退出。等待超时或状态无法确认时保留界面并显示提示，不把停止请求已接受当作退出成功。“停止服务”按钮和单任务停止的含义保持不变。

## 页面与操作

| 页面 | 可以完成的操作 | 需要注意 |
|---|---|---|
| 连接与运行 | 查看本地服务、企业微信和 Codex CLI 状态；启动、停止；配置连接和打开专用登录 | 服务运行不代表企业微信已连接；Agent 本地就绪不代表真实模型已验证 |
| 群与成员 | 添加群和成员、搜索、启用、停用、重新核验群清理 | 本机机主是唯一全局管理员；群状态与成员自己的启停偏好分别保留 |
| 已停用用户 | 按群或用户搜索；重新启用；核验清理；删除当前群用户；从全部群删除 | 重新启用沿用原有资料，不会自动启用所在群 |
| 任务审查 | 筛选全部群和用户的任务；读取公开工具、命令及执行输出；搜索、复制输出；停止任务 | 不展示模型内部思考，也不估算百分比；列表和详情按真实后端状态刷新 |
| 文档管理 | 查看公共区、指定用户私人区和全局临时区；分页读取；删除所选文件；清空当前文件区 | 临时区只有完整清空；不能读取或逐项删除临时文件 |
| 设置 | 切换颜色模式和界面语言、更换或恢复背景；查看和编辑现有服务目录 | 十种语言；颜色模式、语言和背景立即生效，服务目录下次启动生效 |

管理台约每三秒刷新状态及当前任务详情。搜索、筛选和当前选择会保留；任务输出不重复追加相同事件。任务列表上下区域可以拖动分隔条调整大小。长 ID 可通过单元格提示查看完整内容，文档列表支持 Ctrl／Shift 多选，每批最多 100 个文件。

## 停用、恢复和删除

停用成员会立即撤销权限，取消排队及运行任务、待审批和待确认操作，文件、依赖和会话保留。后端可能返回“停用中”或“清理失败”；这些状态不表示清理完成。调查原来的失败后，可以点击“重新核验清理”。删除中或删除失败需要重新预览并完成删除，不能靠重复启停跳过检查。

“删除当前群用户”会删除该群中该用户的成员记录、私人文件、独立依赖和所属 Codex 会话。“从全部群删除”是另一项操作，会列出全部受影响群，且相关成员必须先停用。两种操作都保留公共资料、其他成员数据和共享登录凭据。

删除前，管理台先获取后端预览，显示群、用户、文件数量、容量和会话数，再使用该预览的确认令牌与版本提交。文件或配置变化、预览过期时会拒绝执行，需要重新预览。失败不会显示成删除成功。

## 文件范围

公共区和私人区的“删除所选文件”只处理当前勾选的相对文件名。“清空当前文件区”处理当前选定群的公共区，或该群中某个用户的私人区，包括子目录中的文件，不受当前搜索、分页影响。成员资格、依赖和会话保留。

文件删除弹窗会加载完整清单。清单未加载完或确认已过期时不能确认；可以在清单中滚动核对所有项目。若部分项目失败，会展示逐项结果和剩余数量，已删除的项目不能回滚。

全局临时区由所有群共用。有排队、运行任务或内部临时操作时禁止清空，管理台不会替管理员停止其他人的任务。管理员可以先到任务页主动停止任务，再重新预览。崩溃残留也只能在全局空闲时，核对完整清单后明确清除；根目录保留，不推测归属，不在启动时自动清空。

文档按后端提供的版本分块读取，每块最多 64 KiB。UTF-8 文本可以直接预览，文字预览上限为 2 MiB。其他格式或更大的文档可选择“保存完整副本”，再用本机应用打开；保存副本仍逐块校验文件版本，不改变原文件。读取过程中原文件有变化时，请关闭阅读窗口，刷新后重新打开。

## 离线和设置

界面提供简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语、葡萄牙语（巴西）和俄语。选择后立即切换并保存，下次打开仍使用该语言，不重启服务，也不重建页面。当前搜索、筛选、成员选择和任务输出会保留。导航、页面、状态、按钮和应用确认文案使用所选语言；群 ID、用户 ID、路径、后端原始返回、任务输出及文件内容保留原文。Windows 原生文件选择器等系统窗口使用 Windows 自己的语言。

顶部标题区域已与侧栏、内容背景衔接，设置背景图时沿用相同的背景和主题遮罩。拖动标题区域可移动窗口，右上角仍提供最小化、最大化／还原和关闭，窗口边缘可调整大小。应用内的配置、文件阅读及删除清单窗口采用相同的标题栏；系统确认框和文件选择器仍由 Windows 绘制。

服务离线时，群与成员的配置修改可以保存，下次启动生效；任务、文档读取和数据删除必须在线。连接和目录设置需要先停止服务。机器人 ID 默认脱敏，Secret 使用隐藏输入框；留空表示保留原值。

保存设置会复用原有配置锁、版本检查、目录校验和加密存储。出现版本冲突时，表单输入会保留。点击“重新核对当前设置”，查看并确认新的保存基准后再保存，不会自动覆盖另一份配置。

颜色模式提供“跟随系统 / 浅色 / 深色”，首次默认跟随系统。手动选择会保存到 `runtime\desktop-settings.json`，重新打开仍使用该选择；跟随系统时会同步 Windows 应用主题的变化。主界面、标题栏、下拉框、表格和应用内弹窗使用同一套配色。连接页及配置弹窗提供消息平台和 Agent 下拉框，目前分别只有企业微信和 Codex CLI。

背景支持 PNG、JPEG 和 BMP，文件不超过 20 MB。背景路径保存在 `runtime\desktop-settings.json`，不会复制原图片；移动或删除图片后恢复默认外观。界面保留与当前明暗模式一致的遮罩，避免背景影响文字阅读。

更换服务目录不会搬迁、复制或删除原资料。旧文件、依赖和会话仍在原路径，新目录不会自动继承。所有现有文件布局沿用后端配置。

## 验证与限制

本次已通过四个相关 Go 包回归、core CUJ、go vet、Windows 后端构建、原有 PowerShell 设置／路径／管理验证，以及桌面 Release 构建。桌面没有新增 NuGet 包，构建使用现有离线缓存。

隔离联调使用真实管理进程、受保护本地通道和实际 PowerShell 保存逻辑，配合合成 Agent／平台和临时数据，验证了成员恢复与删除、任务详情与停止、临时区忙碌拒绝及清空、文件清单分页、选择删除、整区清空、版本冲突、清理恢复、离线状态和目录保存。另有千人列表、长 ID、长输出、背景保存与恢复，以及 1360×860、1040×740、960×640 布局渲染检查。多语言修改额外检查十种语言的文案与格式参数、全部六页渲染、即时切换及保存、选择和原文保留，以及隔离原生窗口的最小化、最大化、还原和关闭操作。

真实企业微信多人并发、真实 Codex 登录和模型调用尚未联调；不同显示器上的实际 Windows 缩放、完整键盘操作及原生文件选择器也尚需人工验收。任务历史仅在内存保留最近 50 个已结束任务，每个任务最多 40 条事件，重启后不保留。

## 开发入口

桌面源码在 `D:\MY_SHARE\group-assistant\desktop`，项目文件为 `tongxu.csproj`，命名空间为 `Tongxu.Desktop`。运行项目根目录的 `Build-Desktop.ps1` 可离线构建 `tongxu.exe`；运行 `build.ps1` 可执行原有后端验证并构建后端。两者都不会启动群服务。

接口说明见同目录的 `local-management-api.md`。本轮实施和隔离验证记录位于 `.planning\desktop-20261029`，实际界面截图和联调结果保存在其中的 `evidence` 目录。
