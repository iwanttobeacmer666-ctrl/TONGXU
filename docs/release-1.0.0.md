# 同序 1.0.0

本次将本地完善后的桌面、后台和配置逻辑同步到公开源码，并提供 Windows x64 联网安装器。

- 安装器按 GitHub 最新正式 Release 获取程序，校验下载大小、SHA-256、文件清单和程序版本。
- 缺少兼容的 .NET 10 Desktop Runtime 时，经用户确认后从 Microsoft 下载并校验签名；不要求用户安装 Go 或 .NET SDK。
- 安装布局将配置、登录和工作数据与程序文件分开，保留已有托盘后台运行行为。
- 同步更新检查界面、更新前暂停接收新任务及附件的后台逻辑、相关验证脚本。
- 更新 README，区分源码包、编译程序 ZIP 和安装器的用途与依赖。

## 下载哪个文件

- `TONGXU-Setup-1.0.0.exe`：窗口安装器，自动获取兼容的最新正式程序；运行时依赖缺失时先征求同意。
- `Tongxu-1.0.0-win-x64.zip`：已编译程序，自行准备 .NET 10 Desktop Runtime（x64）后完整解压运行。
- `TONGXU-Source-1.0.0.zip`：与本次提交一致的源码，自行准备 Go、.NET SDK 和模块依赖后编译。
- `SHA256SUMS.txt`：上述附件的 SHA-256 校验值。

CLI、企业微信机器人参数、机主与群 ID、工作目录及专用登录仍由用户配置。本次发布不包含实际账号、群成员、凭据或运行数据。

安装器的版本与程序版本独立。后续兼容更新只需发布新程序 ZIP 并将 Release 标记为最新；下载来源、安装协议或运行环境主版本改变时再更新安装器。已安装的桌面不会因此自动升级。现有桌面更新交接仍面向 MSI，本次没有发布 MSI。

## 验证范围

已完成桌面编译、后台相关模块回归、核心用户流程、静态检查、配置/路径/合成本机管理验证、40 项离线更新检查、14 项布局检查，以及安装器的包校验和异常输入检查。

尚未完成干净 Windows 上的运行环境安装、交互安装/升级/卸载及真实企业微信群任务验收。安装器未做发行者代码签名。
